# BlackFlipper

A Flutter-based Android application designed for Albion Online players to track market data efficiently. This tool helps you monitor price fluctuations across different cities and optimize your trading routes for maximum profit.

### **Note (Important):** 
This project is not yet fully completed and has missing sections. 
Also, Cloud Storage and Cloud Functions were used in the data retrieval phase of the application. 
Anyone is welcome to make additions or modifications as they see fit.

### **✨ Features**
Real-time Price Tracking: Access up-to-date market data powered by the Albion Data Project API.

Item Search: Quickly find specific items using advanced filtering.

City Comparison: Compare prices between Martlock, Lymhurst, Bridgewatch, Fort Sterling, Thetford, and Caerleon.

User-Friendly UI: A modern, fast, and responsive experience built with Flutter.

### **🚀 Installation**
Follow these steps to run the project locally:

Clone the repository:
`git clone https://github.com/rureru/blackflipper.git`

Navigate to the project directory:
`cd blackflipper`

Install dependencies:
`flutter pub get`

Run the application:
`flutter run`
